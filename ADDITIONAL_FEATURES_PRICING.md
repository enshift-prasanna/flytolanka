## 3. Individual Feature Details

### Feature 1: User Accounts & Past Bookings Dashboard
- **Price:** **LKR 7,000**
- **Scope:**
  - Customer registration and login.
  - User profile area (`/my-bookings`) displaying submitted inquiries, selected package, dates, person count, and booking status.
  - Auto-filling customer contact information on booking forms when logged in.

### Feature 2: Admin Dynamic Pax-Based Pricing
- **Price:** **LKR 5,000**
- **Scope:**
  - Input fields in the Admin Panel to set price slabs per package (e.g. 1 pax: $100, 2 pax: $160, 3 pax: $210).
  - Dynamic frontend calculation on tour booking forms updating total cost live as guests select adult/child counts.

### Feature 3: Automated Confirmation System (Email & WhatsApp)
- **Price:** **LKR 4,000** (One-time setup)
- **Scope:**
  - Branded HTML confirmation email sent to the guest immediately after submitting an inquiry.
  - Automated WhatsApp confirmation message sent to the guest's phone number via API.

### Feature 4: Real-Time GPS Tracking (Flutter Android APK + Web Live Map)
- **Price:** **LKR 15,000**
- **Scope:**
  - Lightweight Flutter Android APK running in background on guide/driver's phone, transmitting live GPS coordinates.
  - Dedicated website tracking page (`/track`) where visitors enter a Guide/Trip Code and view the vehicle's real-time position on an interactive map.
